# Ledger Wallet API

A wallet/ledger service built with double-entry bookkeeping and optimistic locking for safe concurrent transfers.

## Tech Stack

Java · Spring Boot · PostgreSQL · Apache Kafka · Docker · JWT · JPA/Hibernate

## Status

In active development — backend first, frontend planned as a later phase (see [phases.md](phases.md)).
